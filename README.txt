MASS FRIEND RUN — Vercel-ready starter

FILES
- index.html, style.css, game.js: the game
- friend.png: replace this with your friend's photo (keep this exact filename)
- telugu-song.mp3: put your Telugu song here (keep this exact filename)

HOW TO ADD YOUR PHOTO AND SONG
1. Use a clear, front-facing photo with your friend's permission.
2. Rename the photo to friend.png and place it beside index.html.
3. Put your song in the same folder and rename it telugu-song.mp3.
4. Do not upload copyrighted music unless you have permission to use it. For a private demo, browser playback still depends on the browser's audio rules.
5. Music starts only after the player taps the Music button (browser autoplay restriction).

RUN LOCALLY
- Open the folder in VS Code.
- Install the VS Code extension "Live Server".
- Right-click index.html > Open with Live Server.
- Or simply open index.html in a browser for a quick test.

DEPLOY TO VERCEL
1. Sign in at https://vercel.com/
2. Create a GitHub repository and upload all files in this folder, including friend.png and telugu-song.mp3.
3. In Vercel choose Add New > Project, import that GitHub repository.
4. Framework Preset: Other.
5. Build Command: leave blank. Output Directory: leave blank (root).
6. Click Deploy. Vercel will give you a public URL.
7. Whenever you update files and push to GitHub, Vercel redeploys automatically.

IMPORTANT
- Keep the photo and MP3 file names exactly as shown.
- Large MP3 files may make deployment slower; compress the audio if needed.
- This is a playful, friendly roast game. Avoid humiliating content and use your friend's photo only with consent.
